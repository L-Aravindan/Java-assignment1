## DIFFERENCE B/W JDK , JRE , JVM 

- JDK : PROVIDES US WITH TOOLS WHICH IS REQUIRED TO DEVELOP JAVA APPS

- JRE : PROVIDES WITH ENVIRONMENT WHICH IS NEEDED TO RUN JAVA PROGRAMS 

- JVM : EXECUTE JAVA BYTECODE BASICALLY


##WHAT IS BYTECODE 
SO WHENEVER AN JAVA PROGRAM IS COMPILED IT PRODUCES AN INTERMEDIATE CODE , THAT INTERMEDIATE CODE IS CALLED AS BYTECODE , WHICH IS EXECUTED BY THE JVM


#WRITE ONCE , RUN ANYWHERE 

JAVA PROGRAMS COMPILED INTO BYTECODE CAN ACTUALLY RUN ON ANY SYSTEM WITH A JVM INSTALLED HENCE MAKING IT PLATOFORM INDEPENDENT .
